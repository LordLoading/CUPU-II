info
the opcode of an instruction is 2 bytes long. any immediate value
is stored in a number of bytes directly following the opcode.
the ammount of immediate bytes can change depending on the data type
(1, 2 or 4 bytes)

there are 8 general purpose registers. all of them behave normally,
except register 0, which is hardwired to a 0x0 constant.

the conditional instructions dont branch directly. if a conditiona
is false, the next instruction will be skipped.
